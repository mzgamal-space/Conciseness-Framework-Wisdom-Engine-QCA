QuenchCluster

Implementation and experiments for the Quench Cluster Algorithm (Noureldin, 2026).

This repository contains multiple Python scripts implementing the Quench Cluster Algorithm, hybrid variants, TSP benchmarking and visualization utilities.

Quickstart
- Requires Python 3.10+
- Install dependencies: pip install -r requirements.txt
- Run an example: python "Quench TSP Benchmark.py"

Contents
- LAPN algorithm implementations
- Quench cluster LAPN_RealTime v1.py: algorithm implementations
- Quench cluster universal v3.*.py: algorithm implementations
- Quench_cluster_v4_hybrid.py, qca_hybrid_poc.py: hybrid proofs-of-concept
- quench_cluster_v4_visualizations.py: plotting helpers
- Quench_Cluster_Algorithm_Noureldin_2026.docx: manuscript draft
